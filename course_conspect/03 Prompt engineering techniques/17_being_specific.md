# Prompt engineering techniques

## Урок 17. Being specific

Ссылка: https://academy.claude.com/courses/building-with-the-claude-api/being-specific

### Главное

Чтобы ответы стали лучше и стабильнее, надо прямо написать, какой ответ
нужен, а не оставлять это на усмотрение Claude.

Пример: «Write a short story about a character who discovers a hidden
talent». Рассказ может быть на 200 слов или на 2000, с одним героем или с
пятью, о любом таланте. Указания в prompt задают Claude конкретную цель.

### Два вида указаний

**1. Требования к ответу (output quality guidelines)** — какими качествами
должен обладать ответ:
- длина;
- структура и формат;
- что обязательно должно быть в ответе;
- тон и стиль.

Пример для рассказа: не больше 1000 слов, есть действие, которое
показывает талант героя, есть хотя бы один второстепенный персонаж.

**2. Шаги (process steps)** — по каким шагам Claude решает задачу. Полезно,
когда нужно, чтобы Claude продумал задачу по порядку или рассмотрел её с
разных сторон до ответа.

Пример для рассказа:
1. Придумать три таланта, которые создают драматическое напряжение.
2. Выбрать самый интересный.
3. Набросать ключевую сцену, где талант проявляется.
4. Придумать второстепенных персонажей, которые усилят эффект.

### Пример: план питания

В курсе после добавления требований балл вырос с 3.92 до 7.86:

```
Guidelines:
1. Include accurate daily calorie amount
2. Show protein, fat, and carb amounts
3. Specify when to eat each meal
4. Use only foods that fit restrictions
5. List all portion sizes in grams
6. Keep budget-friendly if mentioned
```

У нас в уроке 15 было похожее: когда требования из `extra_criteria`
добавили в prompt, балл вырос с 3.0 до 6.3.

### Когда что использовать

- **Требования к ответу** — почти в каждом prompt. Они гарантируют
  стабильный и полезный результат.
- **Шаги** — для сложных задач:
  - поиск причины сложной проблемы;
  - принятие решений;
  - задачи на критическое мышление;
  - когда нужно рассмотреть задачу с разных сторон.

Пример: почему упали продажи команды. Шаги: проверить рыночные метрики,
изменения в отрасли, результаты каждого сотрудника, изменения в
организации, отзывы клиентов. Без шагов Claude может сосредоточиться на
одной причине.

### Вместе

В профессиональных prompt часто используют оба вида: требования задают
формат и содержание ответа, шаги — чтобы Claude продумал задачу полностью.
Так результат стабильный, и Claude учитывает все важные факторы.
