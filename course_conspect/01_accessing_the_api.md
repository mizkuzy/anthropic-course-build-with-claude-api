# Урок 1. Accessing the API

Ссылка: https://academy.claude.com/courses/building-with-the-claude-api/accessing-the-api

Теория, кода нет.

## Путь запроса

1. Клиент (сайт, приложение) → ваш сервер.
2. Сервер → Anthropic API.
3. Модель обрабатывает запрос.
4. API → ответ серверу.
5. Сервер → ответ клиенту.

Запросы к API делать только с сервера. В клиентском коде ключ может украсть любой пользователь.

## Обязательные поля запроса

- API-ключ;
- `model` — имя модели, например `claude-sonnet-4-5`;
- `messages` — список сообщений;
- `max_tokens` — максимум токенов в ответе.

Запрос можно отправить через SDK (Python, TypeScript, JavaScript, Go, Ruby) или обычным HTTP-запросом.

## Как модель создаёт ответ

1. Токенизация — текст делится на токены (слова, части слов, знаки).
2. Embedding — каждый токен превращается в список чисел, который описывает его значения.
3. Контекстуализация — числа уточняются по соседним словам, чтобы выбрать нужное значение.
4. Генерация — модель считает вероятности следующего токена и выбирает его с долей случайности. Затем повторяет.

## Когда модель останавливается

- достигнут `max_tokens`;
- модель сама закончила ответ;
- встретилась stop-последовательность.

## Что приходит в ответе

- сгенерированный текст;
- usage — количество входных и выходных токенов;
- stop reason — причина остановки.
