# Tool use with Claude

## Урок 20. Introducing tool use

Ссылка: https://academy.claude.com/courses/building-with-the-claude-api/introducing-tool-use

### Главное

Claude знает только то, что было в данных обучения. Текущих событий,
данных в реальном времени и внешних систем он не видит. Tools (инструменты)
дают Claude способ запросить свежие данные у нашего приложения.

### Проблема без tools

Вопрос «What's the weather in San Francisco, California?». Без tools Claude
отвечает, что у него нет доступа к актуальной погоде.

### Как работает tool use

Обмен сообщениями между приложением и Claude:

1. **Первый запрос.** Отправляем Claude вопрос и описание, как получить
   дополнительные данные из внешних источников.
2. **Запрос tool.** Claude решает, что данных не хватает, и просит
   конкретные данные.
3. **Получение данных.** Наш сервер выполняет код: вызывает внешний API или
   базу данных.
4. **Финальный ответ.** Отправляем данные Claude, он отвечает на основе
   вопроса и полученных данных.

### Пример: погода

- В prompt добавляем описание, как получить погоду.
- Claude просит данные о погоде для нужного города.
- Сервер вызывает weather API и отправляет результат Claude.
- Claude отвечает на вопрос с актуальными данными.

### Что дают tools

- данные, которых не было при обучении;
- связь с базами данных, API и другими сервисами;
- ответы на основе последних данных;
- Claude сам определяет, какие данные ему нужны, и запрашивает их
  в заданном формате.

Примеры: погода, курсы акций, запросы к базе данных.
