# Урок 2. Getting an API key

Ссылка: https://academy.claude.com/courses/building-with-the-claude-api/getting-an-api-key

## Шаги

1. Открыть https://platform.claude.com/ и войти в аккаунт.
2. Нажать Get API Keys.
3. Нажать Create Key.
4. Workspace — `Default`, имя ключа — например `Anthropic Course`.
5. Скопировать ключ. Он показывается один раз. Если окно закрылось — удалить ключ и создать новый.

## Где хранить ключ

Только в файле `.env` в папке курса. Подробно — в `SETUP.md`, раздел «API-ключ».
