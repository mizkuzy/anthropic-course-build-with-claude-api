# Курс «Building with the Claude API»

Учебный проект по курсу Anthropic Academy:
https://academy.claude.com/courses/building-with-the-claude-api

## Структура

- `course_conspect/NN <Модуль>/NN_<урок>.md` — конспекты, папки модулей
  пронумерованы в порядке курса.
- `lesson_scripts/NN_<что делает>.ipynb` — notebook уроков; файлы данных
  с тем же префиксом (`15_dataset.json`).
- `helpers.py` — общие функции (`add_user_message`, `chat`,
  `print_results`). Переиспользовать, не дублировать.
- `prompt_evaluator.py` — `PromptEvaluator` для модуля Prompt engineering.
- `SETUP.md` — venv и запуск Jupyter.

## Конспект урока

- Своими словами, по-русски, кратко; все команды и зачем они.
- Формат:

  ```
  # <Модуль>

  ## Урок N. <Название>

  Ссылка: <ссылка на урок>

  Notebook: <ссылка на notebook, если есть>

  ### <Раздел>
  ```
- Устаревший для новых моделей приём — абзац «**Неактуально для новых
  моделей.**» перед «Главное», со ссылкой на документацию.
- Если мы сделали не так, как в уроке, — раздел «Что мы поменяли» в конце.
- Без временных пометок вроде «код не проверен»: статус — в чате,
  в конспект только итог.
- Квизы не конспектируем.

## Notebook

- Модель `claude-haiku-5-5` (раньше `claude-sonnet-5-5`).
- Prefill и `temperature` на новых моделях дают 400 — вместо них
  structured outputs (`output_config.format`).
- Строки не длиннее 80 символов, включая текст prompt.
- Запускать в Jupyter во встроенном браузере (Kernel → Restart Kernel and
  Run All Cells), сохранять (Cmd+S), коммитить результаты.
- Jupyter запускать во вкладке терминала: `source .venv/bin/activate &&
  jupyter notebook --no-browser`. Токен вставляет пользователь.

## Как мы работаем

- Кратко, простыми словами, по-русски. Несколько шагов — по одному.
- Делать только то, что попросили; о лишних изменениях спрашивать.
- Коммитить сразу после каждого изменения, маленькими коммитами.
- «На сегодня закончили» — закоммитить, выключить Jupyter, закрыть
  вкладки браузера, удалить временные файлы, `__pycache__`,
  `.ipynb_checkpoints`.
